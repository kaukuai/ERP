# v0.4.3 本機交付與資料保留

更新：2026-11-03。

本版將「GitHub 程式碼更新」與「Windows 本機包」一起交付。Windows 建置流程在檢查通過後，產生附 Node.js 執行環境的 `ERP-Windows` 成品；解壓後雙擊 `start.cmd` 即可使用。

本機版預設把資料保存於使用者的 `ERP-Local` 資料夾，與程式碼分開；關閉後保留資料，新版放在另一個資料夾也會沿用同份設定。已有舊資料時先驗證備份並沿用原位置，實際位置會顯示在啟動畫面。

- 版本更新前備份根庫與所有公司庫，於副本核對既有資料與一致性。
- `backup.cmd` 提供手動備份及全部帳套的備份清單。
- 同份資料有互斥鎖，避免多個版本同時啟動；重複啟動同版可開啟既有服務。
- 已知資料庫遺失、備份驗證失敗或版本不相容時停止，不以空庫替代。
- 本機包不含業務資料、帳密或預設管理員，也不將資料庫上傳至程式碼儲存庫。

完整下載、更新與備份方式見 [Windows 本機版](Windows本機版.md)。本版沒有新增 schema 遷移，仍為版本 12；線上展示維持獨立、可重置的虛構資料。

雲端開發環境目前無法直接操作使用者的 Windows 桌面，因此交付可下載成品，不宣稱已安裝到該電腦。首次需由使用者在 Windows 解壓並啟動。
