# v0.6 表單設計、填寫與完整性複查

左側新增「表單設計與填寫」。可從 11 個通用範本開始，或建立空白表單；包含報價、銷售訂單、採購訂購、詢價、三種案件清單、工作／業務日報、週計畫及車輛月報。抬頭從目前帳套帶入，版型不預填企業專屬條款。

## 編排與使用

1. 按「新增版型」，選擇起始範本。
2. 設定名稱、來源、A4／A5／Letter 或自訂紙張、方向、邊距、字級、框線色。
3. 左側拖曳區塊或用上下移動；右側可改文字、寬度、標籤、字級、框線、對齊、留白及欄位來源。圖片接受 250 KB 以內 PNG／JPEG。
4. 明細表格可增刪、排序欄位、調整欄寬、列高與空白列；可加簽核空格或換頁。預覽可選符合視窗寬度或實際尺寸。
5. 儲存後可複製版型、停用、空白列印及匯出 JSON；其他帳套可匯入這種 JSON，先編輯預覽再儲存。

交易版型：從報價、銷售訂單或採購明細按「選擇表單版型」，再選對應版型。金額、數量及客戶資料來自已保存的來源單據；草稿／取消狀態會標示。自訂列印不能繞過來源與成本權限，也不會開立統一發票。交易版型中的手填欄位可留作紙本填寫；要保存獨立填寫資料，請使用「自行填寫表單」。

填寫表單：清單按「填寫」，填文字、日期、數字、單選、勾選及明細；可先存不完整草稿，確認送出時檢查必填與型別。送出後鎖定內容；取消須填原因，保留原紀錄。可查看歷程及列印／另存 PDF。各筆記錄保留建立時的版型修訂與公司抬頭，後來修改範本不會回改已填紀錄。

填寫紀錄不會自動形成庫存、收付或會計過帳；里程、費用等須人工核對。本版簽核區是列印空格，送出鎖定不等於多階核准或電子簽章。表單有最多 100 區塊、8 個表格、每表 12 欄及 200 筆填寫資料的限制；表格欄名會在列印跨頁時重複。

## 權限與版本

未自訂權限時，完整管理員可設計範本；一般使用者可填自己的紀錄，主管及管理員可查本帳套紀錄，唯讀帳號不可新增或改資料。已有細部授權時，可設定「表單版型設計」與「表單填寫紀錄」的檢視、新增、修改、送出、取消、列印及匯出等動作，配合本人／下階／指定使用者資料範圍。

編輯來源單據與列印來源單據分開檢查。含隱藏欄位的受限帳號，延續原本對原始列印的保守限制。尚無每位使用者對每一指定版型的獨立授權矩陣，也未新增通用表單每個自訂欄位的個別遮蔽。

自行填寫的欄位按整筆表單的資料範圍授權；欄位名稱即使與商品成本、電話等同名，也不會自動繼承主檔的欄位權限。交易帶入列印則仍須通過來源單據及成本權限，兩者應分別設定與驗收。

版型及填寫紀錄都有修訂衝突檢查。修改時發現其他人先保存，會要求重新開啟；不直接蓋掉新版本。版型歷史及填寫事件不可覆寫。

## 這次重新檢查的結果

原 115 項驗收仍為 95 項可操作、6 項部分具備、14 項外部整合，但它們不是全部手冊功能的總數。本次另拆出 16 項，2 項可操作、6 項部分具備、8 項待建置，已顯示在「功能對標與開發驗收」。所以目前不能宣稱所有同類功能都已齊備或比所有產品完整。

主要新增差距包括補打單期限、分欄精度與日期格式、全欄位／逐版型權限、多階簽核、三方核對、品質放行、完整儲位及多幣別。表單設計器也尚未支援原生 Word／Excel 版型匯入、任意合併儲存格、公式、條件區塊及巢狀分組。詳細來源與逐章判定另見專案中的完整性複查文件。

## 修正既有問題

本機模式的 CSV 匯出、資料庫備份及商品圖片網址原先未帶帳套，切換公司後可能仍讀取主帳套。已統一附加目前帳套識別，並用同時保有兩家公司登入的瀏覽器測試，核對 CSV、實際下載 SQLite 的內容及圖片來源。另更新使用指南過時的單公司說明。

舊計價版本只保存明細金額與單頭稅額，新版自訂列印不會將升級時的零值當成逐列稅額。未保存的逐列未稅／稅額／含稅欄位留白並加註說明，預設列印原金額；單頭合計保持原值。折數以百分比顯示。

## 升級與驗證

版本 0.6.0、schema 15，新增表單版型、修訂、填寫紀錄及事件表，原交易資料不覆寫。先用 `scripts/pre-upgrade.mjs --db 資料庫路徑 --all-companies` 在備份副本驗證，再啟動新版。

Windows 資料仍在 `%LOCALAPPDATA%\ERP-Local` 或原選定位置。下載本版 Actions 的 `ERP-Windows` 成品，完整解壓到新的程式資料夾，關閉舊版後開啟 `start.cmd`。啟動器會先做全帳套備份與副本驗證；表單和其他資料一樣保留於本機資料庫。搬移程式資料夾後，需重新設定既有每日備份排程。

本次驗證使用獨立測試資料：`npm run verify` 共 212 項通過；舊版 schema 14 的測試資料在備份副本升級至 15，原資料列完整保留且一致性檢查通過。瀏覽器檢查主要頁面及設計器的 4 種寬度，以及 16 種視窗在 3 種寬度的空白／填入長文字狀態，共 96 個組合，未發現頁面或欄位超出容器。80 列表格輸出 4 頁 PDF，逐頁重複欄名並保留首末列。

本機包已驗證重啟保留、換程式資料夾、完整帳套備份、排程備份、還原副本及遺失資料庫保護。網頁展示以實際打包內容在 3 個輪替處理程序驗證；這不代表已更新正式部署。本機包驗證在建置執行環境進行，不代表已安裝到使用者電腦；列印實體紙張及設備仍須實測。
