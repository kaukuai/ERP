更新：2026-11-02 · 本系統 0.3.0 · 共 115 項需求。

依原廠公開 418 頁手冊八大章整理，另標出原廠現行官網擴充與本公司強化。各列狀態只涵蓋該列驗收行為，不代表整個模組或正式上線已完成。這是獨立功能歸納，不複製廠商程式及版面。

## 本輪完成的可操作驗收項目

- B04 單號規則管理：可設定前綴、分店碼、日／月／年／連續分期及補零位數；保留舊單號並跳過已使用號碼。
- B14 代號更名與帳款重建：代號以穩定 ID 關聯；可預覽庫存／帳款來源差異，管理員核對後自動備份、驗證快照與總帳，再原子重建並留痕。
- B19 非庫存商品與服務：服務／運費可進報價、訂單及採購，不預留或異動實體庫存；進貨記費用，退貨回沖對應帳務。
- B20 商品標籤與條碼列印：支援 Code 128／EAN-13／QR，A4／A5／連續紙及自訂尺寸、數量；每單位可有條碼，實機紙張及掃描器仍需驗收。
- B21 商品圖片管理：管理員可上傳 PNG／JPEG／WebP，驗證格式及大小，登入後才能讀取，商品圖及選品顯示。
- B23 單位字典及多單位換算：基本單位與箱／包等換算比例、各單位條碼及售採購價可維護；單據凍結換算、帶價，進出退及採購以基本量核對。
- B30 銀行分行代碼字典：可維護銀行／分行唯一代碼，資金帳戶連結該分行，供票據及票簿使用。
- P04 無採購單直接進貨：不需事先建採購單，主管可一次建立可追溯來源、核准並入庫立帳，任一步失敗整批回滾。
- P09 採購明細／排行／年度分析：可查進貨／退出／折讓明細，依日期、廠商、商品、分類、業務、部門及月份彙總排行與匯出；未保存的歷史分類列未分類。
- S06 直接銷貨及前台銷售：具核准與庫存權限者可直接銷貨，信用、核准、出庫及立帳同筆交易並保留來源；完整 POS 另列 X10。
- S08 整單折扣分攤：整單價格折扣按各列含／未稅價格基礎分攤，稅額隨明細重算；分批交貨與退貨保留精確分攤及尾差。
- S09 同單混合稅別：同張單可按列設定外加／含稅、稅率含零稅率或免稅；單據、交貨與退貨保存各列稅額，發票介接仍另列。
- S10 出貨條碼比對：批次揀貨可用基本或換算單位條碼比對，多張來源逐列追溯；擋錯品、超量與重複掃描，全部核對後才能出貨。
- I08 庫存帳重建：從不可覆寫流水重算數量、價值及訂單預留，先比差異、自動備份、管理員確認及總帳核對；錯誤整批回滾。
- T05 支票簿與號碼區間：可建銀行票簿起訖及補零規則、自動取下一可用號、空白票作廢與耗用追蹤；全域重複票號會阻擋。

操作入口與限制見 [v0.3 操作與升級](v0.3操作與升級.md)。原有預收付、退款、票據、費用等說明見 [v0.2 操作與升級](v0.2操作與升級.md)。

## 重要邊界

批次收付款與批次掃碼出貨都不等於月底合併立帳。本版仍於每筆出入庫立即立帳；同批揀貨會保留多張來源及出庫單，尚不合併成一張銷貨或發票。

混合稅別及整單折扣是管理系統的計算行為，電子發票仍需選定服務、授權、測試帳號及真實回執。平台與物流未串接，不能用模擬成功替代正式整合。

折讓後的再次實物退貨仍待逐列分攤；有未兌現票據須先處理票據再折退。已有退貨／折讓的收付款，不能直接反向沖銷。採購金額折讓目前記存貨調整損益，進銷費用成本分攤未完成。

盤點及成本匯入的 CSV／XLSX 範圍在各列明確標示。實體紙張、掃描器、印表機、手機及真實長時間 20 人負載仍待驗收。所有 GUI 寫入測試僅使用虛構示範資料。

流水重建先預覽與自動備份，再核對來源快照與總帳；不能重寫歷史流水或補平衡分錄掩蓋錯誤。公司資料庫未執行測試重建或測試交易。
