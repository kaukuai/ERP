# 功能完整性複查與來源 · 2026-11-03

本次結論：**目前沒有全部涵蓋指定手冊的每個操作細節，也不能宣稱比所有國內外 ERP 更完整。** 原 115 項是自行歸納的驗收範圍，不是手冊全部功能的分母。其 95 項可操作、6 項部分具備、14 項外部整合的數字仍成立於各列限定範圍；本次另拆出 16 項檢查，2 項可操作、6 項部分具備、8 項待建置。兩組不可相加作市場覆蓋率。

新版加入表單設計與填寫功能。細部權限、不可覆寫事件、版本衝突、交易原子性、可驗證備份及版型快照，是可用測試證明的能力；這些證據不代表其他產品沒有同等能力，也不構成整體優劣排名。

## 驗證方法與後續優先順序

本次另發現並修正既有本機 CSV／備份／圖片網址未帶目前帳套的問題；在同時保有主帳套與分帳套登入時，以實際下載檔案內容檢驗。

程式回歸使用獨立暫存／記憶體資料庫；瀏覽器使用虛構展示帳套。檢查新表單型別、空白值、長文字、版型修訂、送出鎖定、列印來源及權限、跨帳套、冪等、CSRF、升級副本；再跑既有交易與財務回歸。瀏覽器以 1440、1024、768、390 像素檢查主要頁面及設計器，另產生 PDF 核對。精確通過數與交付成品見 [本版操作說明](v0.6表單設計與複查.md)；測試不能保證沒有任何 bug，實際紙張、設備與正式資料仍需情境驗收。

建議依商業影響處理：先補多階簽核、逐人逐版型及欄位權限差距，再處理三方核對／品管、複合來源月成本、正式發票／POS 串接；儲位、多幣及其他產業模組按使用情境獨立排程。上述優先順序是工程建議，沒有將尚未實作的功能標成完成。
