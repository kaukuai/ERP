# v0.4.2 展示與單機操作

更新：2026-11-03。

本版提供免獨立主機的線上互動展示。使用虛構商品、客戶、單據、倉庫、門市與會員，按「進入示範工作空間」即可操作，方便向客戶說明流程。

## 線上展示

未設定正式後端網址時預設開啟展示；也可明確設定 `ERP_MODE=demo`。部署本版並清除舊的建置／輸出目錄覆寫後，即可使用現有網站網址，不需設定代理密鑰或先建立另一台主機。詳細步驟見 [雲端部署](雲端部署.md)。

可示範報價輸入、送審核准、轉訂單、部分出貨、庫存與帳款連動、單據列印及 CSV 匯出；門市已預先配置展示現金／收款帳戶及會員，可開班、掃碼與收銀。既有進階作業仍沿用實際 ERP 邏輯，並非只顯示靜態圖片。

每個分頁保留獨立的展示資料。重整可接續，列印視窗可取得當下單據；新的獨立分頁從原始資料開始。「重新開始展示」會清除該分頁變更並恢復虛構資料。關閉分頁、八小時未操作、重新部署或瀏覽器清除資料也可能重置，請勿輸入正式公司資料。

展示狀態可跨函式執行個體延續，使用驗證加密保護；短暫資料庫在每次請求結束後清除。展示有帳套數、資料量及檔案限制，大量檔案或備份可能要求縮小範圍。收銀只登錄展示交易，不會實際扣退款或開立正式發票。

## 單機正式使用

不需另租後端主機，網頁服務與資料庫都在同一台電腦。安裝 Node.js 24 後執行 `start.cmd` 或 `npm run dev:company`，瀏覽器開啟 `http://127.0.0.1:4320`，首次建立自己的帳套與管理員。

程式關閉後，本機 `data/company.sqlite`、公司目錄及備份仍會保留；下次用相同指令啟動即可接續。這與線上短暫展示分開，正式使用應定期備份完整資料。

## 正式雲端模式

正式帳套使用 `ERP_MODE=production` 與持久化後端，保留原有驗證與資料隔離。缺少正式設定時仍會拒絕操作，不會自動改用展示資料。展示版完成不代表正式資料移轉、外部發票、金流、設備或維運已驗收。

本版沒有新增資料庫 schema 遷移，仍為版本 12。應用處理器抽為共用模組，單機服務與展示沿用相同的交易、權限、CSRF、冪等及列印邏輯。更新說明及 README 持續使用中性名稱。
